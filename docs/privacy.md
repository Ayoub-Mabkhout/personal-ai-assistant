# Privacy notice

This project is a self-hosted personal assistant. Each installation is run by one
person, its owner, for their own use. It is not offered as a service to anyone else.

## Bank account data

When the owner links their own bank accounts through a licensed open-banking provider
(an account information service provider under PSD2), the assistant reads balances
and transactions for those accounts only, with the owner's consent given in each
bank's own login screen. Consent expires after the period set by the bank, and the
owner can withdraw it at any time in the bank's app or the provider's control panel.

- **Purpose:** tracking the owner's spending against their own allowance, recognising
  transfers between their own accounts, reimbursements and refunds, and reporting
  savings and spending insights to the owner.
- **Storage:** transaction data is kept on hardware the owner controls (their own
  computer and their own server). It is never written to this public repository.
- **Processing:** to classify and explain transactions, the assistant may send the
  relevant transaction details to the AI model provider the owner has configured.
  Nothing is sold or shared for any other purpose.
- **No payments:** the assistant only reads account information. It does not
  initiate payments or transfers.
- **Deletion:** the owner can delete the stored data and revoke the bank consent at
  any time.

## Other data

The assistant's other features (calendar, tasks, mail, phone companion) process only
the owner's own data under the same principles: owner-controlled storage, no sale or
sharing, and model processing only to answer the owner's requests.

## Contact

Privacy questions go to the owner of the installation, through the data-protection
contact registered with the open-banking provider.
