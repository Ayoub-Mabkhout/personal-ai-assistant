# README visuals

- `hero.svg` is an original vector illustration using the project's Dusk Aurora palette.
- `today-light.png`, `money-dark.png`, and `money-detail.png` show the actual dashboard HTML in a browser with synthetic API responses. Network requests were intercepted; no live account, calendar, ledger, or profile data was loaded.
- `voice-to-task.png` is an illustrative, source-inspired native screen from the local launch film. It is not a handset screenshot; the request is fictional.
- Example activities, merchants, appointments, balances, and categories are fictional. These are interface demonstrations, not measured production results.

The launch film and its composition are kept outside tracked source. Its bundled
music does not include sufficiently documented redistribution terms to publish
an audio-bearing asset here. The still images above contain no third-party music.
